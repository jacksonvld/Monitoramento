# Monitoramento e observabilidade

Repositório para estudos, scripts e configurações de monitoramento de serviços e infraestrutura.

## Organização recomendada

Separar os arquivos por ferramenta ou finalidade e documentar, em cada projeto, requisitos, parâmetros, dependências e instruções de uso.

## Cuidados de segurança

Não publicar tokens de API, contas de serviços, senhas, endpoints internos sensíveis ou dados reais de ambientes monitorados. Preferir variáveis de ambiente e modelos com valores fictícios.

> Este README não representa auditoria completa dos arquivos ou do histórico Git.
